# Personal Idea Base

A public collection of project ideas in plain Markdown files.

## Structure
- `ideas/` – Add each project idea as its own `.md` file here.

## How to add an idea
1. Create a new Markdown file: `ideas/idea-name.md`
2. Include basics: `Title`, `Problem`, `Goal`, `Tech`, `Notes`
3. Open a PR to add it here.

## How to share your build
If you implement any idea:
1. Fork/clone this repo
2. Build it in your own space or add notes to the idea file (e.g. `Status: Built`, `Repo: your-link`, `Demo: your-link`, `Learnings: ...`)
3. Open a PR with your update so others can see it too.

**Access:** Public – anyone can read, fork, and submit PRs.
